# 秋招网申助手

秋招网申助手是一款适用于 Chrome 和 Edge 的浏览器扩展，用于集中管理求职资料、识别招聘表单并快速填入个人信息、教育经历、实习项目和简历文件。

## 功能说明

| 功能 | 说明 |
|---|---|
| 资料管理 | 保存基本信息、教育经历、实习经历、项目经历、技能、证书和自定义信息 |
| 多简历切换 | 保存多套相互独立的完整简历，可在设置页管理，并在插件弹窗中快速切换当前简历 |
| 快速填充 | 从插件弹窗启动，自动识别当前网页的招聘表单字段并填入资料 |
| AI 扫描填充 | 从插件弹窗启动，自动识别当前网页的招聘表单字段， AI 匹配后批量填入（需配置 AI） |
| AI 框选补填 | 框选表单模块或自定义区域，只对其中空白字段执行 AI 匹配与填入（需配置可识别图像的 AI） |
| 信息窗口 | 从弹窗点击「打开信息窗口」，优先在浏览器原生侧边栏展开，不支持时回退为独立浮窗；点击单条资料即复制，若已聚焦网页输入框则同时写入 |
| 简历解析 | 支持 PDF、DOCX、Markdown、TXT 和结构化 JSON |
| 投递记录管理 | 新建、查看、筛选、排序、整行编辑、删除，并支持 CSV 导入导出 |
| JSON 备份 | 版本化导入、导出，导入前验证格式并显示摘要 |
| WebDAV 同步 | 保存后自动同步，使用 ETag 防止跨设备静默覆盖 |

## 快速安装

### 普通用户安装

如果你只是想使用插件：

1. 点击当前仓库右侧的 Releases 页面，点击下载最新版扩展压缩包（job-application-helper-extension.zip）。
2. 先将压缩包解压到本地任意文件夹。
3. 打开 Chrome 或 Edge 的扩展程序管理界面。
4. 开启页面内的“开发者模式”。
5. 点击“加载解压缩的扩展”。
6. 选择刚才解压出来的扩展目录。
7. 将“秋招网申助手”固定到浏览器工具栏，方便使用。

浏览器不能直接加载 `.zip` 压缩包，必须先解压，再加载解压后的目录。

## 如何使用

### 配置个人资料

1. 点击浏览器工具栏中的插件图标。
2. 点击“设置个人信息”进入设置页。
3. 依次填写基本信息、教育经历、实习与项目、自定义信息。
4. 点击页面底部“保存”，右上角出现“保存成功”后即可关闭页面。

AI 配置不是必需项。未配置 AI 时，基本信息管理、JSON 简历导入、信息窗口、复制和常规表单填充仍可使用。

### 管理和切换简历

每套简历都保存一份完整、相互独立的个人资料，包括基本信息、教育经历、实习与项目、技能、自定义信息和简历附件。

在设置页的“个人信息设置”标题下方点击当前简历名称，可以：

- 点击其他简历名称，将其切换为当前简历。
- 点击“新建空白”，创建一套新的空白简历。
- 点击某套简历右侧的“复制”，基于其全部内容创建副本，再按目标岗位修改。
- 点击“重命名”修改简历名称。
- 点击“删除”移除不再需要的简历；至少会保留一套简历。

在插件弹窗中，可通过“当前简历”右侧的下拉框快速切换。快速填充、AI 扫描填充、AI 框选补填、简历解析和信息窗口都会使用当前选中的简历。切换前如有未保存的修改，插件会提示保存、放弃或取消操作。

旧版本中保存的单套资料升级后会自动迁移为“默认简历”，原有内容不会丢失。

### 导入简历

在“简历上传”中选择文件：

- JSON、PDF、DOCX、Markdown、TXT：支持本地基础解析；配置 AI 后可获得更完整的结构化识别。

解析结果会写入当前选中的简历并显示在设置页中，确认内容后点击保存。

### 填写网申表单

1. 打开招聘网站的申请或简历填写页面。
2. 点击浏览器工具栏中的插件图标。
3. 在插件弹窗中点击“快速填充”。
4. 插件识别当前页面字段并填入已保存的信息。
5. 自动填充后请人工核对内容。

如果某个字段没有正确识别，可打开“信息窗口”，单独复制或填入基本信息、教育经历、实习经历、项目经历和自定义信息。

### AI 扫描填充

AI 扫描填充比快速填充的准确性更高，使用前需要先在“AI 设置”中配置可用的模型服务。

1. 打开需要填写的网申页面。
2. 点击浏览器工具栏中的插件图标。
3. 在弹窗中点击“AI 扫描填充”。
4. 插件会自动扫描当前页面中仍为空白的可写字段，并按“基本信息”“教育经历”“实习经历”“项目经历”等区域分组处理。
5. 对每一组字段，插件会把页面上下文、字段标签、候选选项和已保存资料一起交给 AI 做匹配。
6. 匹配完成后，插件把结果逐项写回网页，并在页面右下角显示扫描、匹配和填入进度。
7. 如果扫描过程中需要停止，可点击页面提示中的“终止”按钮。

AI 扫描填充不会覆盖已经有值的输入框。对于日期范围、下拉框、开放题和重复字段，完成后仍建议人工复核。

### 使用信息窗口

信息窗口适合逐个处理自动填充未识别的特殊字段，支持原生侧边栏和独立浮窗两种形态：

1. 点击浏览器工具栏中的插件图标。
2. 点击“打开信息窗口”：优先在浏览器右侧的原生侧边栏展开；若浏览器不支持侧边栏，则自动回退为一个独立浮窗。
3. 可按需将窗口切换到单独的浮窗或置顶浮窗形态：
   - 在侧边栏右上角点击“打开浮窗”，即可打开独立浮窗。
   - 在浮窗右上角点击“置顶小窗”，可在浏览器支持文档画中画时让浮窗置顶在网页上方。
4. 使用方式：
   - 直接点击某条资料（如“学校”“专业”“公司”“岗位”或整条自定义信息），内容会复制到剪贴板，复制成功后底部会短暂提示“已复制到剪贴板”。
   - 若希望自动写入网页：先用鼠标点击网申页面中需要填写的输入框、文本域或下拉框，让光标停留其中，再回到信息窗口点击对应字段，插件会尝试写入该输入框；无论是否写入成功，都会同时复制内容，可在写入失败时手动粘贴。



### AI 框选补填

AI 框选补填用于处理整页填充后仍为空白、命名复杂或重复出现的字段。与“AI 扫描填充”相比，它会结合图像判断填充内容。使用前需要先在“AI 设置”中配置可识别图片的模型服务。

1. 打开需要补填的网申页面。
2. 点击浏览器工具栏中的插件图标。
3. 点击“AI 框选补填”，插件弹窗会关闭，网页进入区域选择状态。
4. 将鼠标移动到“基本信息”“教育经历”“实习经历”或“项目经历”等表单模块上，紫色边框会显示当前识别区域。
5. 单击整个模块，或按住鼠标拖出一个自定义矩形区域。
6. 插件只收集选中区域内仍为空白的字段，结合已保存资料交给 AI 匹配并填入。
7. 页面右下角会显示扫描、匹配和填入进度；需要停止时点击“终止”，按 `Esc` 可在选择区域时取消。

AI 框选补填不会覆盖已经有值的输入框。完成后仍需人工检查日期顺序、下拉选项和生成内容。

### 管理投递记录

投递记录用于集中管理已经投过或准备投递的岗位信息，包括公司名称、岗位名、来源站点、职位链接、投递状态、投递日期、工作地点和备注。

新建投递记录有两种入口：

1. 点击浏览器工具栏中的插件图标。
2. 在弹窗右上角点击“新建投递记录”，进入独立的新建页面。
3. 如果当前网页是岗位详情页，插件会优先根据当前页面生成一份草稿，自动带入公司、来源站点或职位链接等信息；如果无法识别，也可以手动填写。
4. 默认投递状态为“已投递”，可改为“待投递”“已笔试”“面试中”“offer”或“终止”。
5. 点击“保存投递记录”后，页面会保留“已保存”状态，方便继续确认内容。

查看和管理已有投递记录：

1. 点击插件弹窗右上角“打开投递记录”，或进入设置页中的“投递记录”页面。
2. 列表支持按公司、岗位、链接、状态、日期、地点等列排序。
3. 点击“筛选”可按公司、岗位、状态、地点等条件缩小范围，点击“清空筛选”可恢复全部结果。
4. 浏览态下，职位链接会显示为可点击的超链接。
5. 点击某一行右侧的编辑按钮后，该行会直接切换为整行编辑状态；修改后点击“保存”即可更新，点击“取消”可放弃本次修改。
6. 点击删除按钮可删除该条记录，删除前会弹出确认提示。

批量迁移或备份投递记录时，可使用列表右上角的 CSV 工具：

- “导出 CSV”：导出当前全部投递记录，方便在表格软件中查看、整理或另存。
- “导入 CSV”：导入以前导出的记录，适合迁移旧数据或批量补录。导入时会尽量保留合法记录，并对状态值不规范或重复项给出提示。

投递记录不会写入“导出完整数据”的 JSON 备份中；如需单独备份或迁移投递记录，请使用 CSV 导入导出功能。

### 备份与同步

设置页的“数据与同步”提供两种备份方式，手动导入导出或使用 WebDAV 自动同步。手动导入导出时不包含投递记录；使用WebDAV 同步时，会包含投递记录。

- “导入完整数据”：选择以前导出的 JSON，检查通过后确认覆盖本地资料。
- “导出完整数据”：下载当前全部资料的 JSON 备份。

完整备份包含全部简历、当前选中的简历、各简历原文件、AI 配置和 API Key，以及 WebDAV 同步设置（服务器地址、用户名、密码）。字段匹配缓存和同步状态不会写入备份文件。旧版单简历备份导入后会自动迁移为一套“默认简历”。

## WebDAV 配置

在“数据与同步”中填写：

- WebDAV 服务器地址
- 用户名
- 密码或第三方应用密码

首次点击“测试连接”时，插件会创建或确认远端目录：

```text
job-application-helper/
└── job-application-helper.json
```

保存同步设置后，点击“立即同步”完成首次上传。启用自动同步后，保存个人资料、解析简历、保存 AI 配置、导入完整备份、更改投递记录都会排队同步。

同步规则：

- 只有本地变化：上传本地版本。
- 只有远端变化：下载远端版本。
- 两端都变化：停止覆盖并显示冲突选择。
- 同步失败：保留已成功保存的本地数据。

坚果云通常使用：

```text
服务器地址：https://dav.jianguoyun.com/dav/
用户名：坚果云登录邮箱
密码：第三方应用管理中生成的应用密码
```

如果返回 401，请检查账号和应用密码；如果返回 403、404 或 409，请确认地址是可写的 WebDAV 根目录，而不是普通网页或分享链接。

## 安装与开发
### 开发与本地构建

如果你需要自行修改代码、重新构建，才需要准备下面的环境：

- Chrome 或 Edge 116 及以上版本
- Node.js 20.19 及以上，或 Node.js 22.12 及以上
- npm

推荐安装最新的 Node.js LTS 版本。

### 一键安装并构建

下载项目后，在项目根目录运行对应脚本：

- macOS：双击 `一键安装依赖.command`
- Windows：双击 `一键安装依赖.bat`

脚本会依次完成：

1. 检查 Node.js 和 npm。
2. 使用 `npm ci` 安装锁定版本的依赖。
3. 运行全部自动化测试。
4. 构建可加载的 `dist/` 目录。


### 常用命令

```bash
npm test
npm run build
npm run lint
npm run dev
```

- `npm test`：运行备份格式与 WebDAV 同步测试。
- `npm run build`：类型检查并生成 `dist/`。
- `npm run lint`：运行静态代码检查。
- `npm run dev`：启动 Vite 开发服务，扩展调试仍需构建后加载 `dist/`。

## 数据说明

- 默认数据保存在浏览器扩展的 `chrome.storage.local`。
- JSON 导入文件上限为 20 MiB。
- 手动备份和 WebDAV 文件为明文 JSON，可能包含个人信息、简历和 AI API Key。
- 只有主动配置并启用 WebDAV 后，数据才会上传到用户自己的 WebDAV 服务。
- 卸载扩展或清除扩展数据前，建议先导出完整备份。
