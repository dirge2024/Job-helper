# 简历下拉框间距与弹窗布局调整

## 目标

在不改变简历管理与切换逻辑的前提下，压缩信息设置页简历菜单的横向占用，优化标题、菜单与下方内容区之间的纵向间距，并移除插件弹窗中的重复简历名称。

## 信息设置页

- 简历下拉触发器与展开菜单不再使用 680px 的宽布局，改为适合“简历名称 + 三个文字操作”的紧凑宽度，并保留窄屏自适应。
- 展开后，每行简历名称与“重命名 / 复制 / 删除”之间仅保留 12–16px 间距；名称过长时截断，操作文字保持完整。
- “个人信息设置”标题与简历下拉框之间的间距略微增加。
- 简历下拉框与下方灰色内容区域之间的间距缩小约一半。
- 保持菜单展开、切换、新建、复制、重命名、删除、未保存保护及删除确认逻辑不变。

## 插件弹窗

- 移除“当前简历”下方单独显示的活动简历名称。
- 同一行仅显示左侧“当前简历”和右侧简历下拉框。
- 两者字号一致、垂直居中。
- 保持切换行为、禁用状态和错误提示逻辑不变。

## 验证

- 更新组件测试，确认弹窗不再重复输出活动简历名称。
- 运行简历相关测试。
- 对修改文件执行局部 lint，并运行构建验证 TypeScript 与样式引用。
