# 奖项荣誉与经历字段精简设计

## 目标

在每套简历的“实习与项目”末尾增加独立的“奖项 / 荣誉”模块，并从整个项目中彻底删除实习成果、项目成果和项目技术栈三个字段。

## 数据模型

新增 `AwardInfo`：

- `id: string`
- `name: string`，必填
- `role: string`，可空
- `date: string`，可空
- `description: string`，可空

在 `UserProfile` 中新增 `awards: AwardInfo[]`。每套简历分别维护自己的奖项列表，不与其他简历共享。

从数据模型中删除：

- `ExperienceInfo.achievements`
- `ProjectInfo.achievements`
- `ProjectInfo.technologies`

## 兼容与迁移

读取本地旧资料、旧 JSON 备份或 WebDAV 数据时：

- 保留实习和项目的其他字段。
- 忽略并清除上述三个废弃字段。
- 旧数据没有 `awards` 时补为空数组。
- 不因废弃字段存在而拒绝导入旧备份。

后续保存与导出不再包含废弃字段。

## 设置页

在“实习与项目”页面最后增加“奖项 / 荣誉”区域，沿用现有经历编辑组件的视觉语言。

每项提供：

- 名称：单行输入，必填。
- 担任角色：单行输入，可留空。
- 获取时间：单行日期文本，可留空。
- 详细描述：多行文本，可留空。

支持新增、编辑、删除和排序。只有名称为空时阻止保存并显示就近错误，其余字段均允许为空。

实习和项目编辑表单中彻底移除：

- 实习“成果”输入项。
- 项目“成果”输入项。
- 项目“技术栈”输入项。

## 信息窗口

新增“奖项 / 荣誉”分区，按现有信息项的点击复制规则展示非空字段。

- 名称始终展示。
- 担任角色、获取时间、详细描述仅在有值时展示。
- 没有奖项时不显示空分区。

实习和项目分区不再展示废弃字段。

## 简历解析与 AI

本地解析、结构化 JSON 和 AI Schema 增加 `awards`。解析器识别“奖项、荣誉、获奖经历、荣誉奖励”等常见标题。

AI 与本地解析输出不再生成实习成果、项目成果和项目技术栈字段。读取旧 AI 结果时忽略这些字段。

## 表单匹配与填充

增加奖项字段的语义匹配：奖项名称、担任角色、获取时间、详细描述。

删除实习成果、项目成果和项目技术栈的专用匹配与填充规则。通用描述字段仍分别使用实习描述和项目描述。

## 备份与同步

当前 JSON 备份和 WebDAV 同步完整保存 `awards`。旧版备份继续兼容导入，但废弃字段会在规范化时丢弃。备份版本仅在现有格式无法兼容新增可选数组时升级；优先保持当前版本并通过默认空数组兼容。

## 验证

- 数据模型与规范化测试覆盖新奖项和旧字段清理。
- 设置页测试覆盖奖项增删改、排序、名称必填和其他字段可空。
- 信息窗口测试覆盖奖项展示、复制和空分区隐藏。
- 解析、AI Schema、表单填充、备份与 WebDAV 测试覆盖新字段。
- 全项目搜索确认生产代码不再引用三个废弃字段。
- 运行完整测试、lint、构建和差异检查。
