# 侧边栏收录岗位改版实施记录

## 需求范围

- 工具栏图标直接打开 Chrome 原生右侧侧边栏。
- 侧边栏顶部展示 Logo、求职助手和小号 `Ctrl+Shift+A`，中间区域独立滚动，底部固定投递看板与简历配置。
- 仅保留收录当前岗位和一键填充两个主要操作。
- 收录当前岗位在按钮下方展开紧凑表单，自动读取公司、岗位、城市、当前页面链接和当天日期；链接隐藏保存，备注在投递看板中维护。
- 投递阶段默认为已投递，城市通过 datalist 记忆历史输入。
- 保留原有简历解析接口和中文字段 JSON 写入活动简历的流程。
